## 2. Timeline strip markers (during play)

- **Marker colors.** When a card's mini icon lands on the strip, a color overlay washes over it as it settles, over about 600ms, finishing as a soft tint at about 40% so the icon remains visible beneath. Draw a thin ring in the same color.
  - **Scenario markers:** `#eacc9d`
  - **Out of your hands markers:** `#85837f`
- **Always centered.** Each marker's center sits exactly on its chronological point on the line, both horizontally and vertically. Markers are never pushed above or below the line.
- **The first marker is the one exception.** Because the first card (2027) sits very close to Now, it may not fit at its exact position. In that case, nudge it to the right only as far as needed to clear the Now marker, and keep it vertically centered on the line. Don't move it down.
- **Every later marker** sits at its true chronological position on the shared time scale, with no nudging.

## 5. Replays favor unseen cards

When a player chooses Play again **in the same session** (without reloading the page), they should mostly see cards they haven't seen before, while the story stays as cohesive as ever.

- Keep a set of every Scenario and Event id shown during this session, in memory. It resets when the page reloads.
- **Round 1:** pick randomly among opening cards not yet seen. Only if all five have been seen, pick from all of them.
- **Rounds 2–4:** the candidates are still only the two cards in the Next list (or the Event's Next list), so cohesion is never broken.
  - If exactly one candidate is unseen, choose it.
  - If both are unseen, or both have been seen, use the normal selection rule.
- **Events:** among eligible Events, prefer unseen ones. Only pick a seen Event if every eligible one has been seen.
- Future stories already avoid immediate repeats. Keep that.

My simulation of this rule shows the share of cards that are new in each replay at about 99% in game 2, 96% in game 3, 91% in game 4 and 85% in game 5. Add this replay simulation to `tools/check-story.js` and print the same figures.
