## Phase 2: the storylets engine

- **Migration** (`archive/tools/migrate-v5.js`): 142 Next entries became Appears when conditions and openers on 26 cards, with no new writing. Events' `After round` became `Round`. Every Scenario got `Round` from its section.
- **Openers use `last flag`, not `flag`.** The brief's example writes migrated openers as `flag r2-datacenter/A | The first answer came on a battlefield.` A plain `flag` stays true for the rest of the game, so in a 7-round game that sentence could introduce a card two rounds after the decision it answers. I added `last flag X` ("set by the most recent Choice or the Event after it") and the migration uses it. In a 4-round game the two are identical; in 7 rounds it keeps every lead-in next to the decision it follows. Alternative: plain `flag` as written, accepting the occasional stale lead-in.
- **Selection, as built.** The pool is every card for this round whose Appears when holds, unseen this game, not dated before the last card or Event (and, from Phase 3, After humanity cards only after a tipping point). Each card's score is its Weight × `Continuity bonus` per continuity tier (tier 1: its conditions mention a flag the last Choice set; tier 2: one the Event just set, since the Event is the most recent thing the player saw) × `Steering bonus` (from `Steering from round`, if it grounds one of the two nearest Futures) × the Agents arc bonus or penalty × `Novelty bonus`. Before `Best-fit from round` the draw is in proportion to score; from then on the best card (ties broken by v4.1's explore score, or the tiebreaker score in the last round, then file order) is drawn with `Best-fit pick chance`, otherwise one of the rest in proportion to score.
- **Why multipliers, with big defaults:** with `Continuity bonus` and `Steering bonus` at 1000, the new engine reproduces v4.1's rules exactly (the linked cards win, round 2 is 50/50, rounds 3 and 4 give the steered or more decisive card 60%). Phase 5 tunes them down for the 7-round game, so cards that don't continue the last thread can win sometimes.
- **Session novelty** stays a filter, as in v3.4, so the play-test's replay check still means something: if any of the most continuous cards is new this session, cards already seen this session drop out of the pool. `Novelty bonus` (default 1, off) is there if a softer preference is ever wanted.
- **Weight now means "how likely a card is to be drawn"** on Scenarios and Events (the brief's meaning). In v4.1 it multiplied a card's Effects, but no card used it. On milestones it still multiplies Effects.
- **Value scale.** Every condition (Appears when, Likelihood, openers, milestone Conditions, Requires, tipping points) and the final match use the Values multiplied by `Value scale rounds` (4) ÷ rounds played so far, capped at 1. So in a 4-round game nothing changes, and after 7 rounds the Values are multiplied by 4/7. Alternative: raw Values in mid-game conditions; I chose one consistent scale so that thresholds mean the same thing everywhere.
- **Safety net.** If a round's pool is ever empty: cards marked `Fallback: yes` ignore their conditions; then any unused card of the round in date order; then any unused card of the round. `check-story.js` counts every use.
- **The Event a card follows.** v4.1 preferred Events whose Next list shared a card with the Choice's. Without Next lists, an Event is "linked" if some card of the next round mentions both its flag and the Choice's. This only applies to Events without a Likelihood (the v4.1 content), and Phase 3 replaces it with adaptive Events.
- **Compatibility test** (`node archive/tools/compat-test.js`, 100,000 games each, v4.1 from its git tag against the migrated file on the new engine): **PASS.** Largest Future share difference 0.41 points (The Garden 10.3% → 10.0%, Common Ground 13.7 → 13.9, Afterlife 5.2 → 5.5, Elsewhere 6.5 → 6.1, The Gilded Ones 9.8 → 9.6, The Last War 5.4 → 5.3, Blackout 3.0 → 2.9, The Oracle 12.4 → 12.8, The Long Middle 33.7 → 33.9). The same 36 cards and Events appear, and exactly the same "How we got here" sentences can appear for every Future. The only card that moved more than a point is r3-finland (15.8% → 14.5%): when two linked cards tie on every score, v4.1 broke the tie by their order in the Next list and the new engine uses file order.
- **check-story.js** was rewritten for v5: exact path counting and exact best-play reach are gone (too slow with conditions). Distinct paths are now a sampled (Knuth) estimate, about 45,000 for the migrated content against v4.1's exact 37,902 (the estimator is unbiased but noisy, so the table says "about"). Best-play reach is replaced by a "seeking reach": a simulated player who always picks the Choice that sets the Future's flags, grounds it, or moves the Values nearest its Targets.

At most 3 per game (`Most Events per game`), never in two transitions in a row, none after a tipping point. On a replay, Events not yet seen this session are preferred, as before. Tuned in Phase 5.
- **Era drift uses half points:** round 3 power +0.5, control −0.5; round 5 power +1, handover +0.5, reality +0.5; round 6 equality −0.5, unity −0.5; round 7 power +1. Every Choice and Event moves Values by whole points, so totals of half a point mean **no game can end with a Value at exactly zero** (0.0% in simulation, against 79% for 4-round v4.1 games). The direction of each nudge follows the brief's idea of the technology advancing on its own (more capability, a little more handing over and moving online, a little less oversight, equality and unity). Alternative: whole-point drift on power and handover only, which still leaves many zeros on the other four Values. Effect after scaling is ±0.3 at most, except Power (+1.4).
- **Arc 1 (agents).** A hidden Agents counter; `Agents: +1` on 18 existing Choices that hand decisions to AI, let it act on its own, or put machine efficiency first (listed below). From round 4, once it reaches 3, the flag agents_era is set. During it, cards with `Focus: agents` get the Agents bonus (100) and, from round 5, other cards whose conditions don't mention agents_era get the Agents penalty (0.2). Nothing on screen announces it.
- **Arc 2 (tipping points).** A `Tipping point: <conditions> | war|collapse|runaway` on a Choice is checked (with the scaled Values, after that Choice's Effects) as it is made. If it holds, the beat for that type replaces "As a result…" as a full-screen interstitial (no card, no image, Continue to go on), a dark marker (`#5e5a55`, a small disc) joins the strip at that card's date, and the flags after_humanity and the beat's id are set. If it doesn't hold but every Value is within 1 point, near_miss is set. The three beats are in a new `# TIPPING POINTS` section with a Headline (used in the results timeline), a Timeline label and the Future each leads to (war → The Last War, collapse and runaway → Blackout). Each beat is a Grounded by entry of its Future, so "How we got here" names it.
- **After a tipping point, milestones pass silently** (the brief doesn't say). A "Progress levels off as governments hold back" milestone right after the war would read wrong. Alternative: keep showing them; the capability curve would still be accurate, but the captions wouldn't.
- **Flags in Requires**, and "How we got here" always includes what set a required flag: the engine remembers which Choice, Event or beat first set every flag, and when a Future requires flags, those decisions are shown first. `check-story.js` checks every game, and also checks statically that every Choice that can set a required flag is in that Future's Grounded by list.
- **Continuity also counts openers.** A card continues the thread if its Appears when *or its openers* mention a flag the last Choice set. This lets a card appear in any game (no Appears when) while still being the natural next card after particular decisions. The compatibility test still passes at 0.41 points with this rule.

## Phase 5: balance and testing

Final numbers (100,000 random games, `node tools/check-story.js`): The Garden 10.6%, Common Ground 12.8%, Afterlife 5.1%, Elsewhere 5.7%, The Gilded Ones 8.3%, The Last War 4.8%, Blackout 4.8%, The Oracle 4.9%, The Pause 4.3%, Glass Houses 4.3%, Two Kinds 4.2%, Inheritance 5.9%, A Second Chance 2.7%, Overgrowth 2.3%, **The Long Middle 19.4%**. Tipping point 6.8% (war 1.9, runaway 2.1, collapse 2.8), agents era 11.3%, near miss 4.8%. 1.89 Events per game. 0.0% of games end with a Value at exactly zero. Replays: 99.7% of cards are new in game 2. The safety net is never used, and none of the "never" checks fire.

What I changed to get there, and why:

- **Value scale rounds: 5, not 4.** The brief says to multiply the Values by 4 ÷ rounds played. With 7 rounds that is 4/7, and it pulled almost every game toward the middle: a random player's choices don't all push the same way, so 7 of them add up to less than 7/4 of 4 of them. The Long Middle rose to 39% and the older Futures fell to about a third of their v4.1 shares (The Garden 3%, The Oracle 5%). Using 5/7 restores the older Futures to roughly their v4.1 shares. Alternative: keep 4/7 and loosen every Future's Targets, which would have meant rewriting what each one stands for. This is one setting (`Value scale rounds`), easy to change back.
- **The Long Middle threshold: 3.4** (was 3.0). It matters less than it used to: most Long Middle games now fail every Future's Requires rather than being too far from all of them.
- **Era drift on Power halved** (0.5 in rounds 3, 5 and 7, so 1.5 in all, plus the other half points). With four milestones that each add Power, a typical game ended at about +5 Power after scaling, against roughly +3 in v4.1, which crowded every Future toward Common Ground. sota-builders no longer adds Power, and sota-economy and sota-builders can't happen during a pause (`not flag pause`), which is also what a halt on more powerful AI would mean.
- **Requires loosened slightly on five older Futures**, because a diagnostic of Long Middle games showed they most often just missed these rules: The Garden (control ≥ 0.5, equality ≥ 0.5, reality ≤ 0.5), Afterlife (reality ≥ 1.5), The Gilded Ones (equality ≤ −1.5), Elsewhere (reality ≥ 0.5), The Last War (unity ≤ −0.5, control ≤ 0.5). Their Targets are unchanged.
- **The six new Futures moved from the brief's starting points:** The Pause requires `flag pause, power <= 3` with Targets power 0, control +3, unity +2; Glass Houses `control >= 1.5`; Two Kinds `equality <= 0`, Targets equality −2, power +4; Inheritance Targets power +4, handover +5, control −1; A Second Chance `flag near_miss, control >= -1.5, unity >= -2.5`, Targets control +1, unity +1. Overgrowth is as briefed. Each was set from where players holding its flag actually end up, so that holding the flag and meeting the rules usually leads there.
- **Near miss effects (new setting): control +2, unity +1,** applied quietly when a near miss happens. The brief says the world "came close and turned back"; without this, players who nearly tip are by definition low on Control and almost never qualify for A Second Chance (0.1%). Alternative: no effect and a looser Requires; that made A Second Chance a grab bag of reckless games.
- **A sixth tipping point:** r5-sunshade/A (letting one AI run the sunshade, collapse), for more tipping points in round 5. Thresholds were moved so that each tipping Choice tips about a third of the time it's made and nearly tips about a fifth of the time. A few cards got a higher Weight or extra openers so the flags behind the new Futures come up often enough: r3-policing and r5-socialcredit (1.5), r3-implants (2), r4-embryo and r7-longevity (1.5), r4-selfimprove and r5-launch (2), r5-coordinator (1.5), r5-moratorium (2).
- **Two more Choices tend life** (keeping the zoo animals fed, sealing half the reactors safely), plus the seed vault kept frozen and the fleets powered down, so that Overgrowth is reachable.
- **Agents +1 on two more Choices:** r2-robots/A (robots in every home and hospital) and r4-preacher/A (following the AI preacher). Inheritance's Grounded by now lists all 36 Agents Choices.
- **Event likelihoods** rebalanced so each Event is close to 15–50% of games. Because an Event can't follow an Event, a likely Event after round 2 suppresses round 3's, and so on, so the likelihoods had to be balanced across rounds rather than set one by one.
- **Four new questions reworded** (r4-selfimprove, r4-chips, r5-sunshade, r7-vote) because they repeated the question of a card that can come right before them. The play-test's flash monitor caught it: the same words vanishing and reappearing look exactly like a flicker.

**Targets not met, and why:**
- **A Second Chance 2.7% and Overgrowth 2.3%** (target 4–8%). These can't both meet their targets while the arcs meet theirs. Every A Second Chance game needs a near miss (target 5–10%, now 4.8%), and every Overgrowth game needs a tipping point in round 4 or 5 (the brief's rule of two life-tending Choices after it rules out round 6) inside a 5–8% tipping rate, and then needs two of two or three After humanity Choices to tend life. Raising them to 4% would mean tipping points in roughly 12% of games. I kept the arcs at their targets.
- **Near miss 4.8%** (target 5–10%): within sampling noise of 5%; some seeds measure 5.0%.
- **ev-talks 13.8%** (target 15–50%): by the brief's own rule the talks only collapse when Unity is low or drones were built, so in many games it can't happen at all.
- **Phase 5 play-test (desktop):** 1,002 games, **0 failures**, on a frozen copy of the final v5 build (commit 05ce5a9 apart from CLAUDE.md, which doesn't affect play), in 5,003 s. 39 games reached a tipping point and 63 the agents era; all 15 Futures were reached (The Long Middle 206, The Garden 112, Common Ground 109, The Gilded Ones 79, Elsewhere 61, Inheritance 60, Glass Houses 57, Afterlife 51, Blackout 50, The Oracle 45, The Last War 43, The Pause 42, Two Kinds 35, A Second Chance 31, Overgrowth 21). An earlier, interrupted run found only one problem, now fixed: four new cards repeated the question of a card that could come right before them.
- **Walk-through** (v3.6 §6, done unattended): full games at a slower speed with `--shots`, including a tipping-point game that ended in Overgrowth and a session with two Play again replays, and screenshots looked through one by one. It found one real problem: the tipping point's dark disc sat at exactly its card's year and was hidden behind that card's marker. It now sits 0.4 years later. The beat's overlay was also darkened slightly, so the card behind it no longer shows through.
- **Phone (300 games requested):** the strip ran out of label rows in late rounds on 390 px, failing every game at first. Two phone-only changes: the strip's time scale starts at Now on phones (the history is on Home), and the phone strip is 38 px taller so the last-resort third label row fits. After them, 218 games passed and 42 failed (a session stops at its first failure), every failure a late label overlapping another in round 7. Left for Levi: it needs a design choice (MORNING-REPORT.md lists options). Phone failures don't block v5.

## v5.1: one story that climbs, in a world whose AI matches the cards

Levi asked for: superintelligence to be able to follow a runaway tipping point; no card about something (headsets, say) unless an earlier decision touched it; every earlier Choice shaping the next card, the most recent most; 6 rounds whose stakes keep rising. After a first pass, his screenshot of a game (election deepfake, hospital attack, São Paulo policing, pandemic, California trust scores, Singapore and Johor, the end of jobs, Glass Houses) showed it still didn't hold together: three "progress slowed" milestones while the cards assumed a nine-day AI vaccine, an AI-run city-state and the end of work; no throughline; stakes going up and down; a "2040s" card after a 2043 one. He chose a strong spine, gating high-capability cards plus new slow-AI cards with AGI made likely but superintelligence not, a role that grows with the stakes, and one v5.1 commit. Everything below is in that commit.

**Rounds and dates**
- **6 rounds**: 2027 | 2028–2031 | 2032–2035 | 2036–2040 | 2041–2045 | 2046–2050. Every card kept its date and took the round its date falls in. Ids kept their v5 numbers, so an id's number is no longer its round. Events were redated into the gaps between rounds, and their text changed to match.
- **Exact years everywhere.** The seven "2040s" and "Late 2030s" cards got years inside their rounds (r4-twocities moved to 2040 and round 4). The validator now refuses any other kind of date.

**Capability that matches the cards**
- Before v5.1 the next card was drawn before the milestones up to its date were worked out, and no card could ask about capability. Now `capabilityAt` resolves those milestones first, exactly as the transition will (the same `resolveTo`), and cards can require `capability >= AGI`, `reached sota-robots`, `reached sota-asi` or `not reached sota-asi`. A check (never violated in 100,000 games) confirms no card assumes more AI than its world has.
- What each card assumes: AGI for the Nobel, uploading, self-improvement, the London shutdown, the cure for cancer, AI-designed embryos, Singapore, Europe's coordinator, the climate AI, AI rights, the UN seat, the dimmed sun, the pandemic vaccine and the confession; AGI and robots for the factories and the end of jobs; superintelligence for the self-copying carbon machines. The aging treatment and the caregivers were left at AGI and robots, and the AI newsroom at Expert, because their stories don't need more and the slow-AI pools would otherwise run dry.
- **AGI is likely, superintelligence is not**: AGI in 2031 at power ≥ 0; a new milestone, **AGI two years late** (2033), for most worlds that held back (power ≥ −1, control ≤ 3); otherwise "Progress steadies", now dated 2033 and redefined so it doesn't contradict the gauge's Expert label. AGI is reached in about 95% of games. Superintelligence needs power ≥ 3 and no `restraint` (the lab that paused itself), about 52% of games. "Meets its limits" can't follow superintelligence, and "AI runs the economy" can't follow the AI bust.
- **One slowdown at most**: Progress steadies, levels off and meets its limits are marked Slowdown. Only the first is shown; later ones still apply, quietly.
- **Superintelligence after a runaway**: a tipping beat can list `**Milestones:**` that still happen after it, and tip-runaway lists sota-asi. Collapse and war still silence everything after them.
- **Eight new slow-AI and climbing cards** (`New in v5.1`): the AI bust (2041), human checkers return (2042), power rationed for AI (2043), anyone can be named from a photograph (2044), machines care for the old (2046), a ceiling on AI (2047), one network of the world's cameras (2047) and who owns AI's inventions (2048). Each has sources fetched and checked on Wikipedia (the dot-com crash, Mata v. Avianca, Ireland's data centers, Clearview AI, Japan's aging population, Asilomar 1975, Interpol, DABUS), openers, an image description and Grounded by lines.

**A spine instead of a cloud of links**
- The first pass counted every flag a card's openers mentioned as continuity. After I wrote about 550 openers, nearly every card was linked to nearly every decision, so continuity stopped meaning anything. Now **Follows** is the only thing that drives continuity, and openers are wording only.
- **Storylines**: every card belongs to one or more of nine (information, surveillance, work, medicine, minds, race, planet, ai-rule, autonomy). Its Follows lists its storylines' cards from the round before (strength 1) and two rounds before (0.5), the Events of those storylines (0.5), and the Choices that lead to it most directly (+0.5). A Choice now also sets its card's id, so a card can follow "any decision on r3-policing". Choice-level links alone covered too little (half the cards had no strong cause in the last two rounds).
- **The spine** is the weight of each storyline over the player's cards (decay 0.7 per round), the strongest scaled to 1. A card's score is multiplied by Spine bonus (20) raised to its strongest storyline's weight. A first version took only the single strongest storyline and broke ties by listing order, so surveillance cards were almost never on the spine (São Paulo policing appeared in 0.3% of games); the weighted version fixed it.
- **Best-fit is off** (from round 7): picking the top card 60–75% of the time, with ties going to the explore score, made a few cards win almost every game. Cards are now drawn in proportion to their scores.
- **Steering** only applies to cards that continue the story, so it can no longer pull in an unrelated topic to reach a Future.
- **Topic gates** now name the cards that introduce a subject (`any flag r2-glasses, r3-worlds, …`) instead of broad topic flags.
- Results: 84% of cards after round 1 continue the player's storylines, and 96% follow, at full strength, a decision from the last two rounds. The audit's 30 story timelines read as stories; for example, the deepfake leads to the near-war at sea, then São Paulo, then California, then face search, then one network of cameras, and ends in Glass Houses.

**Stakes and role that climb**
- **Scale** on every card (local, national, bloc, world), with Round scales local, national, national, bloc, bloc, bloc and a 0.3 penalty below them: 0.9% of cards fall below their round's scale. California's trust-score vote and the end of jobs were rewritten as the first of many countries.
- **Round influence** 0.75, 1, 1, 1.25, 1.5, 1.5: later Choices move the world further.
- **Questions** grow with the scale: 27 were rewritten, from what a city or "your country" should do to where "your country" stands to what "the world" should decide.
- **Openers**: about 330 new ones in v5.1, keyed to specific Choices and, since cards can now follow whole cards, to earlier cards, each saying how the smaller story grew into the larger one. 1.0% of lead-ins fall back to a default.

**Balance**
- Weights were reset, then set to even out the storylines (the work storyline drew too many games into the AI giants and Singapore; surveillance and implant cards were too rare). Two more Choices set `watched` (AI checking every message after the near-war, a walled national internet).
- A war tipping point was added to refusing the moratorium (unity ≤ −2, power ≥ 4), and three tipping conditions were loosened a little. Tipping is now 8.6%, just over the 5–8% band, which gives Overgrowth 6%.
- **Targets not met**: Glass Houses 3.8%, Two Kinds 2.0% and A Second Chance 1.8% (target 4–8%), Elsewhere 3.6%, near miss 4.2% (target 5–10%), and ev-crash, ev-talks, ev-strike and ev-blight under 15%. With a strong spine, a Future tied to one storyline is reached about as often as that storyline is followed. I chose coherence over forcing those storylines into more games; more setters or cards on them would raise them.
- Agents arc: threshold 2 and the penalty from round 4, since there are fewer rounds; four early Choices lost their Agents +1. Overgrowth's rule is now `Mostly flags` (tended_life holds while at least half the After humanity Choices tend life).
- `archive/tools/compat-test.js` no longer reproduces v4.1, as expected, since continuity changed.

**What the 20 games showed**
- **Capability was the same in every game.** Chips 2028, AGI 2031 and robots 2036 in 20 of 20 games, then superintelligence or a plateau in 2038, the economy in 2043 and builders in 2048. AGI needed only `power >= 0`, robots had no condition, and the curve bent only at milestones. A player who broke up the AI giants and lived through the AI bust still got AGI in 2031.

Round 6 rarely offered a card leading to the Futures that most often lead (The Gilded Ones, The Last War, The Oracle, Blackout). `r4-twocities` showed up in 8 of 20 games.

**Capability**
- **Milestones follow the Values.** `sota-agi` (2031) now needs `power >= 1` and no restraint or pause. `sota-agi-late` (2033) needs `power >= -0.5`, and `sota-steady` takes the rest. `power >= 1` is the median scaled power at 2031 (measured over 4,000 games), giving AGI on time in 64%, late in 26%, never in 9%. `sota-robots` (2036) needs on-time AGI. The new `sota-robots-late` (2040, **Counts as** `sota-robots`, so robot cards still work) covers the rest, including worlds without AGI, because robots don't need AGI to arrive eventually. `sota-asi` also needs `capability >= AGI`. The alternative was a new hand-written Pace field on 234 Choices, which would duplicate power.
- **The first slowdown is always shown,** even beside a gauge mover (the one case where a stretch shows two milestones). A never-check fails any game that shows a card about AI stalling without a slowdown before it (315 of 10,000 games before the fix).

## After v5.3: AI climbs by default, and a plateau has to be earned

**The problem.** Levi's game ran AGI, two years late (2033), then AI wins a Nobel (2035), then *Pandemic stopped by AI* (2039), then **Progress levels off** (2040). The plateau had no Condition. It was the fallback whenever superintelligence's `power >= 3` wasn't met, so about half of all games plateaued, racing worlds included, often with only the default Because line.

**Levi's model.** AI keeps climbing to AGI and superintelligence unless the player makes several slowing choices, reaching up to the global level, so that investors stop seeing returns, each bigger system costs too much power and money, and people lose faith. The potential is still there. The world stops paying to find out.

**The Brake counter.** It is built like the Agents counter. Thirty slowing Choices carry `**Brake:**` (+0.5 for weak ones such as the watermark law or the AI glasses tax, +1 for most, +2 for a pause or the worldwide pause call). A brake on a world-scale card, or a Choice that sets `pause` or `restraint`, also sets `brake_world`. Conditions can test `brakes`.

**Milestones.**
- `sota-agi` needs `brakes <= 1`, so one brake isn't enough to delay it.
- `sota-steady` (AGI never comes) moved ahead of `sota-agi-late` and needs `brakes >= 3, flag brake_world` by 2033 (0.6% of games).
- `sota-agi-late` is the fallback.
- `sota-plateau` moved ahead of `sota-asi` and needs `brakes >= 2, flag brake_world`. `sota-asi` needs only `capability >= AGI, not flag pause`.
- I tested 2, 2.5 and 3 for the plateau. At 3, the plateau showed in 4% of games and Back to Earth fell to 1.2%. At 2.5 the shares were 6% and 2.1%. At 2 they are 17% and 4.5%, inside Back to Earth's target. Two brakes, one of them global, is "several": for example a treaty plus a national power cap.

**The money framing.** The plateau's text is rewritten as "Investors Stop Paying for the Next Leap in AI, and Progress Levels Off", with new Because lines and an economic default. `r4-plateau` became "Investors Stop Paying for Smarter AI…", with the label "The money for AI runs out".

**Datacenter backlash.** New Event `ev-backlash` ("Towns turn away data centers", 2032, national, Brake +1). Democracies vote new sites down and China keeps building, so it never sets `brake_world` and can't plateau the world alone. The story is fictional and grounded in real local opposition (Data Center Watch, 2025; EirGrid's Dublin limits), but states no real facts.

**Results** (100,000 random games):
- AGI reached in 98.9% of games, on time in 86.9%. Superintelligence in 82.1%, plateau in 16.9%.
- Flow targets moved to 90–100%, 75–95% and 70–92%.
- Back to Earth 4.5%, The Garden 6.6%, The Oracle 4.7%, The Long Middle 27.0%.
- Still flagged, as in the first run of this change: The Pause, Glass Houses, Two Kinds, A Second Chance, near miss, and ev-backlash at 6%.

## v5.4: the world follows the player, with no contradictions

Levi's rules for this version: no Future story may contradict an explicit choice; every card must make logical, progressive sense; contradictions are tracked by developer checks, never shown to players. The decisions he made on the requirements audit (`review/requirements-audit.md`) are carried out here, along with a few more found while doing it.

**Brakes are signed.** Racing Choices carry negative brakes (−0.5 to −2, "Let it run" −2, letting the cap expire −2), so the 2040 outcome follows the balance of the player's decisions. A positive brake on a world-scale card, a pause or restraint sets `brake_world`. Only positive brakes count toward it.

**The milestones, in order.**
- AGI on time at a balance of 1 or less; "Progress steadies" at 3 or more with a global brake.
- **Recursive self-improvement** (2038, new level "Self-improving", Pace 1, Growth 3% a year; superintelligence also grows 5% a year, so it climbs even without self-improvement) only while the balance is 1 or less. The self-improvement card now requires it and names it.
- In 2040, **AI held at the line** (new; a slowdown after a pause call or a human review of every version, in a world that was improving itself), else **Progress levels off** (money; balance ≥ 2 and a global brake), else superintelligence.
- In 2048, AI runs the economy in unbraked superintelligence worlds; "Progress meets its limits" needs brakes; "AI becomes ordinary" otherwise.
- "Machines build machines" follows the balance, not the power Value.
- Every milestone that moves the gauge is shown in a stretch (recursive self-improvement and superintelligence can share one), with the first slowdown and the latest other milestone beside them. Without this, robots and cheap intelligence would never have shown.

**The graph.**
- The fill moves only as years pass (the Interlude, milestones), not at the card draw or an Event.
- A major Choice (Brake of 1 or more either way) reshapes the projection over 3 seconds while "As a result…" shows. Minor Choices don't bend it; the old bend from every Choice's power Effect is gone.
- 256 samples over 2000–2064, so every whole year is a sample and no bend reaches back into the past. A check redraws the curve after every step of 3,000 games and fails on any change at or before the fill.
- Tanh was replaced by a linear climb with a soft knee above 0.9, and Gauge trend height is 0.42. Racing worlds now read 0.30 (2040), 0.38, 0.52, 0.74, 0.94 (2060), an exponential shape; superintelligence without self-improvement climbs from 0.27 to about 0.45 (it often meets its limits in 2048); plateau and held worlds stay near 0.3.
- Recursive self-improvement's growth stops at any later slowdown. Without that, held worlds kept climbing.

## v6.1: the pause as a moment, and a counting Interlude

## Launch layout (October 2026)

**Two branches.** `main` on GitHub (`lrstein/a-matter-of-time`, private) holds only a "coming soon" page at `site/index.html`, built as an orphan commit so the full history isn't on it until launch. All work is on `launch`, which merged `main` with `-s ours`, so operation spirit rain is a plain fast-forward with no conflicts.

**site/ is the deploy, as it is.** The alternative was keeping `dist/` and having Cloudflare build it. Publishing `site/` directly means what Levi plays locally is byte for byte what goes live. `tools/build.js` stayed under its name (Cloudflare's build command) but now only checks `site/`, so a private file in `site/` fails the deploy instead of going out.

**404.html.** Without a top-level 404.html, Cloudflare Pages treats a site as a single-page app and serves index.html with a 200 for every unknown path. Then `/image-studio/.env` would "return" the game instead of a 404. `site/404.html` makes every unknown path a real 404.

**Archived image, not a deleted field.** The 14 generated fronts moved to `image-studio/published/`. Each card's path is kept as `**Archived image:**` under an empty `**Image:**`, rather than in a setting that turns art off. The parser ignores the field, so no game code changed, and `publish.py` still finds the Image line to fill. The site check fails on any image in `site/images/cards/` that no Image field uses.

**Docs out of the nested CLAUDE.md files.** `content/CLAUDE.md` and `js/CLAUDE.md` would have been published from inside `site/`. They are now `docs/content.md` and `docs/engine.md`, and the root CLAUDE.md says to read them before editing those folders. `start.command` moved to `tools/` with the other dev tools.
